## 1. Abstract

In modern democratic societies, political polarization has deepened beyond simple ideological differences into "affective polarization"—a state of emotional hostility toward the opposing camp. However, existing social science research has struggled to capture public opinion in real-time due to its reliance on surveys. Conversely, engineering approaches have focused primarily on surface-level sentiment classification, often overlooking the structural dynamics between political actors.

To overcome these limitations, this study proposes a hybrid architecture that combines the contextual reasoning capabilities of Large Language Models (LLMs) with **TuringDB (a high-performance in-memory graph engine) and PostgreSQL (a relational database)**. We extracted "Targeted Attitudes" between political entities from news texts and quantified them as "Social Impact Scores" using the **Dynamic Contextual Propagation (DCP) algorithm**. Experimental results successfully visualized "Hostile Symbiosis" networks forming around specific figures in South Korean political news, suggesting that this system is a powerful tool for identifying conflict structures in digital media.

**Keywords:** Computational Social Science, Affective Polarization, LLM, TuringDB, PostgreSQL, Hybrid Database, Dynamic Contextual Propagation (DCP), Knowledge Graph

## 2. Introduction

### 2.1. Background: Social Conflict Through Data
From the perspective of "Social Physics," language acts as the physical atoms that form social relationships. Voluminous news data online serves as a massive record of how our society "heroizes" or "demonizes" specific targets. This research is an attempt to interpret the philosophical question "Why do we hate each other?" through the tools of data science.

### 2.2. Limitations of Existing Research
Traditional rule-based extraction or simple statistical sentiment analysis face the following challenges:
1.  **Contextual Ambiguity:** They fail to capture irony, sarcasm, or omitted subjects frequently found in political rhetoric.
2.  **Lack of Relational Context:** They treat "A criticized B" as an isolated event rather than part of an accumulated structural conflict.
3.  **Single Repository Constraints:** Pure graph databases struggle with large-scale transaction processing, while relational databases are inefficient for complex network operations. It is difficult to satisfy both real-time analysis and data persistence simultaneously.

### 2.3. Research Objectives
This study aims to combine the **interpretative power of LLMs (humanities strength)** with the **TuringDB-PostgreSQL hybrid system (engineering strength)** to reconstruct hidden social networks and visualize them dynamically. Specifically, we present an architecture that ensures both the speed of in-memory computation and the stability (data persistence) of relational databases.

## 3. Proposed System and Methodology

### 3.1. Overall Data Pipeline
The system consists of four stages: **[Collection] - [Intelligent Extraction] - [Relationship Correction (DCP)] - [Hybrid Storage]**.

### 3.2. TuringDB-PostgreSQL Hybrid Schema Design
We adopted a hybrid architecture to balance real-time graph computation performance with long-term data persistence.
-   **TuringDB (In-memory Layer):** A lightweight graph engine based on Rust/Python that handles complex network operations like the DCP algorithm in real-time within memory.
-   **PostgreSQL (Persistence Layer):** Ensures the persistence of all collected node and edge data and manages log data for time-series analysis.

An extended schema including the **`social_impact_score`** field was designed to express the intensity of social conflict beyond simple sentiment.

*   **Edge Schema Definition (JSONB in PostgreSQL):**
```json
{
  "relation_id": "edge_unique_id",
  "source_id": "politician_A_hash",
  "target_id": "politician_B_hash",
  "type": "Attitude",
  "properties": {
    "action_verb": "heavily criticized",
    "sentiment": "Negative",
    "social_impact_score": 0.85,  // Calculated via DCP algorithm
    "impact_factors": {
       "virality": "High",
       "resonance": "Detected"
    },
    "timestamp": "2024-05-30T10:00:00"
  }
}
```

### 3.3. Dynamic Contextual Propagation (DCP) Algorithm
We propose the **DCP (Dynamic Contextual Propagation)** algorithm, which corrects the social impact of a statement by considering the network position of the speaker.

*   **Principle:** When the attitudes already held by the speaker's allies toward a target resonate with the current statement, the Social Impact Score is amplified. This is designed to **detect "organized offensives" and visualize them as thicker edges in the network**.

## 4. Implementation & Validation

### 4.1. Extraction Performance in Complex Sentences
In-context learning using LLMs (such as GPT-4 or HyperCLOVA X) showed excellent performance in handling the unique ambiguities of the Korean language.
*   **Case 1 (Omitted Subject):** *"Poured out harsh words toward the presidential office."* → Successfully reconstructed the speaker (Subject) from previous paragraphs through contextual inference.
*   **Case 2 (Irony/Sarcasm):** *"Mocked it as 'mind-boggling logic'."* → Correctively classified positive phrases ("mind-boggling") as negative sarcasm.

### 4.2. DCP Algorithm Simulation Results
The validity of the algorithm was verified using a custom-built Python simulator (based on NetworkX).
*   **Scenario:** Spokesperson B criticizes Opposition Leader C (Base intensity: 0.6).
*   **Analysis:** A TuringDB query confirms that B's superior, **Party Leader A**, already holds a strong negative sentiment (0.9) toward C.
*   **Result:** Due to the resonance effect, the **final impact score is corrected (increased) to 0.69**.
*   **Interpretation:** This numerically proves that the statement is not just a personal opinion but an organized offensive based on partisan logic.

## Appendix: DCP Algorithm Simulation Code
```python
import networkx as nx

class PoliticalNetworkSimulator:
    def __init__(self):
        self.graph = nx.DiGraph() # Mocking TuringDB environment
        
    def add_historical_record(self, subject, target, sentiment, weight):
        """Load historical relationship data"""
        self.graph.add_edge(subject, target, sentiment=sentiment, weight=weight)
        
    def get_allies(self, subject):
        """Identify friendly relationships (Allies)"""
        allies = []
        if self.graph.has_node(subject):
            for neighbor in self.graph.successors(subject):
                if self.graph.get_edge_data(subject, neighbor)['sentiment'] == 'Positive':
                    allies.append(neighbor)
        return allies

    def dcp_algorithm(self, subject, target, current_sentiment, base_intensity, alpha=0.3):
        """
        [Dynamic Contextual Propagation Algorithm]
        Corrects the social impact score of a current statement by reflecting the attitudes of nearby allies.
        """
        allies = self.get_allies(subject)
        resonance_score = 0
        
        for ally in allies:
            if self.graph.has_edge(ally, target):
                history = self.graph.get_edge_data(ally, target)
                # Resonance occurs when ally's attitude matches mine
                if history['sentiment'] == current_sentiment:
                    resonance_score += history['weight'] 
        
        # Final score calculation: (1-a)*own_score + (a*resonance_score)
        final_score = (1 - alpha) * base_intensity + (alpha * resonance_score)
        return min(final_score, 1.0)
```
