# 국회의원 관계도 시스템 - 기능 가이드

## 🎯 접속 주소
**http://localhost:3100**

---

## 📱 3가지 뷰 모드

### 1. 그래프 뷰 (Graph View) 🌐

**버튼**: "그래프 뷰"

#### 기능
- ✅ **3D WebGL 그래프 시각화**
  - 300명의 국회의원을 3D 공간에 표시
  - 20,000+ 관계를 선으로 연결
  - 실시간 인터랙티브 조작

- ✅ **의원 사진 표시**
  - 각 노드에 의원 사진이 원형으로 표시
  - 정당별 색상 테두리
  - 고해상도 이미지 지원

- ✅ **정당별 색상 구분**
  - 🔵 더불어민주당: 파란색
  - 🔴 국민의힘: 빨간색
  - 🟠 조국혁신당: 주황색
  - ⚪ 무소속/기타: 회색

- ✅ **마우스 조작**
  - **좌클릭 + 드래그**: 그래프 회전
  - **우클릭 + 드래그**: 그래프 이동
  - **스크롤**: 줌 인/아웃
  - **노드 호버**: 의원 정보 툴팁 표시

- ✅ **범례 (Legend)**
  - 정당별 색상 설명
  - 관계 타입 설명
  - 좌측 하단에 표시

#### 사용 방법
1. 상단 검색창에 의원 이름 입력 (예: "이재명")
2. 자동완성 목록에서 선택
3. 선택한 의원과 연결된 네트워크가 3D로 표시됨
4. 마우스로 그래프를 자유롭게 탐색

#### 표시되는 정보
- **노드 정보** (호버 시)
  - 의원 이름
  - 소속 정당
  - 지역구
- **엣지 정보**
  - BELONGS_TO: 정당 소속
  - SAME_PARTY: 같은 정당
  - REPRESENTS: 지역 대표

---

### 2. 리스트 뷰 (List View) 📋

**버튼**: "리스트 뷰"

#### 기능
- ✅ **그리드 레이아웃**
  - 300명 의원을 카드 형태로 표시
  - 반응형 그리드 (화면 크기에 따라 자동 조정)
  - 스크롤 가능한 목록

- ✅ **의원 카드**
  - 의원 이름 (큰 글씨)
  - 정당 배지 (색상 구분)
  - 지역구 정보
  - 소속 위원회
  - 당선 횟수

- ✅ **정당별 색상 배지**
  - 각 정당마다 고유 색상
  - 한눈에 정당 구분 가능

- ✅ **호버 효과**
  - 카드에 마우스 올리면 강조 표시
  - 부드러운 애니메이션

#### 사용 방법
1. "리스트 뷰" 버튼 클릭
2. 스크롤하며 의원 목록 확인
3. 각 카드에서 의원 상세 정보 확인

#### 표시되는 정보
- **기본 정보**
  - 이름
  - 소속 정당
- **상세 정보**
  - 지역구
  - 소속 위원회
  - 당선 횟수 (초선/재선/3선 등)

---

### 3. DB 구조 뷰 (Database Structure) 🗄️

**버튼**: "DB 구조"

#### 기능
- ✅ **4개 탭 구성**
  - 📊 개요
  - 🏛️ 정당별 분석
  - 📦 노드 구조
  - 🔗 엣지 구조

- ✅ **실시간 통계**
  - 총 노드 수: 308개
  - 총 엣지 수: 20,589개
  - 정당 수: 8개
  - 의원 수: 300개

#### 탭별 상세 기능

##### 📊 개요 탭
- **노드 타입 설명**
  - Member (의원): 300개
  - Party (정당): 8개
  - 각 타입의 역할 설명

- **엣지 타입 설명**
  - BELONGS_TO: 300개
  - SAME_PARTY: 20,279개
  - REPRESENTS: 10개
  - 각 관계의 의미 설명

##### 🏛️ 정당별 분석 탭
- **8개 정당 카드**
  - 정당명
  - 소속 의원 수
  - 주요 의원 5명 (사진 포함)
  - 정당별 색상 구분

- **표시되는 정당**
  1. 더불어민주당 (171명)
  2. 국민의힘 (107명)
  3. 조국혁신당 (12명)
  4. 개혁신당 (3명)
  5. 진보당 (3명)
  6. 무소속 (2명)
  7. 사회민주당 (1명)
  8. 기본소득당 (1명)

##### 📦 노드 구조 탭
- **Member Node 구조**
  ```
  Node ID: member_{id}
  Labels: ["Member"]
  Properties:
    - id: 고유 번호
    - name: 이름
    - party: 소속 정당
    - region: 지역구
    - committee: 소속 위원회
    - election_count: 당선 횟수
    - image_url: 사진 URL
  ```

- **Party Node 구조**
  ```
  Node ID: party_{정당명}
  Labels: ["Party"]
  Properties:
    - name: 정당명
  ```

##### 🔗 엣지 구조 탭
- **BELONGS_TO 관계**
  - 시각적 다이어그램
  - 의원 → 정당
  - 300개 관계

- **SAME_PARTY 관계**
  - 시각적 다이어그램
  - 의원 ↔ 의원
  - 20,279개 관계

- **REPRESENTS 관계**
  - 시각적 다이어그램
  - 의원 → 지역
  - 10개 관계

## 🔍 검색 기능

### 위치
- 모든 뷰 상단에 위치
- 항상 접근 가능

### 기능
- ✅ **실시간 자동완성**
  - 입력하는 즉시 후보 표시
  - 최대 10개 결과 표시

- ✅ **검색 결과 표시**
  - 의원 이름
  - 소속 정당 (색상 배지)
  - 지역구

- ✅ **선택 기능**
  - 클릭하면 해당 의원의 네트워크 표시
  - 그래프 뷰로 자동 전환

- ✅ **초기화 버튼**
  - X 버튼 클릭으로 검색 초기화
  - 전체 그래프로 복귀

### 사용 방법
1. 검색창 클릭
2. 의원 이름 입력 (예: "이재명", "김기현")
3. 자동완성 목록에서 선택
4. 선택한 의원의 관계 네트워크 표시

## 💡 사용 팁

### 1. 특정 의원 탐색
```
검색 → 의원 선택 → 그래프 뷰에서 관계 확인
```

### 2. 정당별 의원 확인
```
DB 구조 → 정당별 분석 탭 → 원하는 정당 카드 확인
```

### 3. 전체 의원 목록 확인
```
리스트 뷰 → 스크롤하며 확인
```

### 4. GraphDB 구조 학습
```
DB 구조 → 개요/노드 구조/엣지 구조 탭 확인
```

### 5. 관계 네트워크 분석
```
검색으로 의원 선택 → 그래프 뷰에서 연결 관계 확인
```

## 🐛 문제 해결

### 그래프가 표시되지 않음
1. 브라우저 콘솔 확인 (F12)
2. WebGL 지원 확인
3. 페이지 새로고침 (Ctrl+F5)

### 이미지가 표시되지 않음
1. 백엔드 서버 상태 확인
2. 네트워크 탭에서 이미지 URL 확인
3. CORS 설정 확인

### 검색이 작동하지 않음
1. 백엔드 API 상태 확인
2. 의원 이름 정확히 입력
3. 네트워크 연결 확인

### 느린 성능
1. 브라우저 캐시 삭제
2. 다른 탭 닫기
3. 하드웨어 가속 활성화
