# 국회의원 관계도 시스템 사용 가이드

## 🌐 접속 방법

### 메인 애플리케이션
**URL**: http://localhost:3100

이 주소로 접속하면 다음 3가지 뷰를 사용할 수 있습니다:

---

## 📱 화면 구성

### 1. 그래프 뷰 (기본)
**버튼**: "그래프 뷰"

**기능:**
- 🎨 3D WebGL 그래프 시각화
- 👤 의원 사진이 노드에 표시
- 🎨 정당별 색상 구분
  - 파란색: 더불어민주당
  - 빨간색: 국민의힘
  - 주황색: 조국혁신당
  - 회색: 무소속/기타
- 🔍 검색 기능
- 🖱️ 인터랙티브 조작
  - 좌클릭 + 드래그: 회전
  - 우클릭 + 드래그: 이동
  - 스크롤: 줌 인/아웃
- 📊 실시간 통계 패널

**사용법:**
1. 검색창에 의원 이름 입력 (예: "이재명", "김기현")
2. 자동완성 목록에서 선택
3. 선택한 의원의 관계 네트워크가 3D로 표시됨
4. 마우스로 그래프를 회전하고 탐색

---

### 2. 리스트 뷰
**버튼**: "리스트 뷰"

**기능:**
- 📋 의원 목록을 그리드 형태로 표시
- 🖼️ 의원 사진과 기본 정보
- 📊 통계 정보

**사용법:**
1. "리스트 뷰" 버튼 클릭
2. 의원 목록을 스크롤하며 확인
3. 각 의원의 정당, 지역 정보 확인

---

### 3. DB 구조 뷰 ⭐ NEW!
**버튼**: "DB 구조"

**기능:**
- 📊 GraphDB 전체 구조 시각화
- 🏛️ 정당별 의원 분석
- 📦 노드 구조 상세 설명
- 🔗 엣지(관계) 구조 설명
- 📈 실시간 통계

**탭 구성:**

#### 📊 개요 탭
- 전체 통계 (노드 수, 엣지 수)
- 노드 타입 설명
  - Member (의원): 300개
  - Party (정당): 8개
- 엣지 타입 설명
  - BELONGS_TO: 소속 관계
  - SAME_PARTY: 같은 정당 관계
  - REPRESENTS: 대표 관계

#### 🏛️ 정당별 분석 탭
- 8개 정당별 의원 목록
- 각 정당의 소속 의원 수
- 주요 의원 5명 표시 (사진 포함)
- 정당별 색상 구분

**표시되는 정당:**
1. 더불어민주당 (171명)
2. 국민의힘 (107명)
3. 조국혁신당 (12명)
4. 개혁신당 (3명)
5. 진보당 (3명)
6. 무소속 (2명)
7. 사회민주당 (1명)
8. 기본소득당 (1명)

#### 📦 노드 구조 탭
- Member Node 구조 설명
  - Properties: id, name, party, region, committee 등
  - 코드 형식으로 표시
- Party Node 구조 설명
  - Properties: name

#### 🔗 엣지 구조 탭
- BELONGS_TO 관계 시각화
  - 의원 → 정당
  - 300개 관계
- SAME_PARTY 관계 시각화
  - 의원 ↔ 의원
  - 20,279개 관계
- REPRESENTS 관계 시각화
  - 의원 → 지역
  - 10개 관계

- 그래프 뷰 ↔ 리스트 뷰 ↔ DB 구조 뷰
- 버튼 클릭으로 즉시 전환

## 📊 GraphDB 구조 이해하기

### Node (노드)
```
Member (의원 노드)
├─ id: 고유 번호
├─ name: 이름
├─ party: 소속 정당
├─ region: 지역구
├─ committee: 소속 위원회
├─ election_count: 당선 횟수
└─ image_url: 사진 URL

Party (정당 노드)
└─ name: 정당명
```

### Edge (엣지/관계)
```
BELONGS_TO (소속)
의원 --[BELONGS_TO]--> 정당

SAME_PARTY (같은 정당)
의원A <--[SAME_PARTY]--> 의원B

REPRESENTS (대표)
의원 --[REPRESENTS]--> 지역
```

## 💡 사용 팁

### 1. 특정 의원의 관계 탐색
1. 검색창에 의원 이름 입력
2. 그래프 뷰에서 관계 확인
3. 마우스로 그래프 회전하며 탐색

### 2. 정당별 의원 확인
1. "DB 구조" 버튼 클릭
2. "정당별 분석" 탭 선택
3. 원하는 정당 카드 확인

### 3. GraphDB 구조 학습
1. "DB 구조" 버튼 클릭
2. "개요" 탭에서 전체 구조 파악
3. "노드 구조", "엣지 구조" 탭에서 상세 정보 확인

### 4. 의원 목록 확인
1. "리스트 뷰" 버튼 클릭
2. 스크롤하며 의원 정보 확인

## 🔧 기술 스택

### Frontend
- React 18 + TypeScript
- Vite (빌드 도구)
- React Force Graph 3D (3D 그래프)
- Three.js (WebGL 렌더링)
- TanStack Query (데이터 관리)
- Axios (HTTP 클라이언트)

### Backend
- FastAPI (Python)
- In-memory Graph Storage
- Image Manager (Pillow)

### Database
- GraphDB (In-memory)
- 308 Nodes (300 의원 + 8 정당)
- 20,589 Edges (관계)

## 🐛 문제 해결

### 그래프가 표시되지 않음
1. 브라우저 콘솔 확인 (F12)
2. WebGL 지원 확인
3. 페이지 새로고침

### 이미지가 표시되지 않음
1. 백엔드 서버 상태 확인
2. 이미지 URL 확인
3. CORS 설정 확인

### 검색이 작동하지 않음
1. 백엔드 API 상태 확인
2. 네트워크 탭 확인
3. 의원 이름 정확히 입력
