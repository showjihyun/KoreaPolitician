## 1. 초록 (Abstract)

현대 민주주의 사회에서 정치적 양극화(Political Polarization)는 단순한 이념의 차이를 넘어, 상대 진영에 대한 정서적 적대감인 '정동적 양극화(Affective Polarization)'로 심화되고 있다. 그러나 기존의 사회과학 연구는 설문조사에 의존하여 여론의 실시간성을 확보하기 어려웠으며, 공학적 접근은 텍스트의 표면적 감성 분류에 치중하여 행위자 간의 구조적 역학 관계를 간과해 왔다.

본 연구는 이러한 한계를 극복하기 위해 거대언어모델(LLM)의 문맥 추론 능력과 **Rust 언어 기반의 고성능 오픈소스 그래프 데이터베이스인 TuringDB**를 결합한 융합 분석 프레임워크를 제안한다. 우리는 뉴스 텍스트에서 정치적 객체 간의 '지향적 태도(Targeted Attitude)'를 추출하고, 이를 **동적 문맥 전파(DCP) 알고리즘**을 통해 사회적 파장 점수(Social Impact Score)로 정량화하였다. 실험 결과, 한국 정치 뉴스에서 특정 인물을 중심으로 형성되는 **'적대적 공생(Hostile Symbiosis)'** 관계망이 뚜렷하게 시각화되었으며, 이는 본 시스템이 디지털 미디어상의 갈등 구조를 규명하는 강력한 도구임을 시사한다.

**주제어:** 계산사회과학, 정동적 양극화, 거대언어모델(LLM), TuringDB, 동적 문맥 전파(DCP), 지식 그래프

## 2. 서론 (Introduction)

### 2.1. 연구 배경: 데이터로 보는 사회적 갈등

'사회물리학(Social Physics)'의 관점에서 언어는 사회적 관계를 형성하는 원자(Atom)와 같다. 온라인상의 방대한 뉴스 데이터는 우리 사회가 특정 대상을 어떻게 영웅화하거나 악마화하는지를 보여주는 거대한 기록물이다. 본 연구는 인문학적 질문인 "우리는 왜 서로를 혐오하는가?"를 데이터 과학적 도구로 해석하려는 시도이다.

### 2.2. 기존 연구의 한계

기존의 규칙 기반(Rule-based) 추출이나 단순 통계적 감성 분석은 다음과 같은 한계에 직면한다.

1. **문맥의 모호성:** 정치적 수사(Rhetoric)에 자주 등장하는 반어법(Sarcasm)이나 주어 생략을 포착하지 못한다.
2. **관계의 부재:** "A가 B를 비난했다"는 사실을 개별 사건으로만 처리할 뿐, 이것이 축적된 구조적 갈등임을 파악하지 못한다.
3. **시스템의 비효율성:** 기존 그래프 DB(Neo4j 등)는 무거운 리소스를 요구하여 개인 연구 환경이나 엣지 컴퓨팅에서의 활용이 제한적이다.

### 2.3. 연구 목표

본 연구는 **LLM의 해석 능력(인문학적 강점)**과 **TuringDB의 구조화 능력(공학적 강점)**을 결합하여, 텍스트 속에 숨겨진 사회적 관계망을 복원하고 이를 동적으로 시각화하는 것을 목표로 한다.

## 3. 제안 시스템 및 방법론 (Methodology)

### 3.1. 전체 데이터 파이프라인

본 시스템은 **[수집] - [지능형 추출] - [관계 보정(DCP)] - [고성능 저장]**의 단계로 구성된다.

### 3.2. TuringDB 기반 데이터 스키마 설계

본 연구는 Rust 언어로 구현되어 메모리 안전성과 I/O 효율이 뛰어난 **TuringDB**를 채택하였다. 특히 단순한 감성을 넘어 사회적 갈등의 강도를 표현하기 위해 **`social_impact_score`** 필드를 포함한 확장 스키마를 설계하였다.

* **엣지(Edge) 스키마 정의:**
```json
{
  "relation_id": "edge_unique_id",
  "source_id": "politician_A_hash",
  "target_id": "politician_B_hash",
  "type": "Attitude",
  "properties": {
    "action_verb": "맹비난했다",
    "sentiment": "Negative",
    "social_impact_score": 0.85,  // DCP 알고리즘으로 산출된 점수
    "impact_factors": {
       "virality": "High",
       "resonance": "Detected"
    },
    "timestamp": "2024-05-30T10:00:00"
  }
}

```



### 3.3. 동적 문맥 전파 (DCP) 알고리즘

단순한 발언의 강도를 넘어, 발화자의 네트워크적 위치를 고려하여 파급력을 보정하는 **DCP(Dynamic Contextual Propagation)** 알고리즘을 제안한다.

* : LLM이 분석한 텍스트 자체의 감성 강도
* : 발화자(Subject)와 그 동료(Neighbor) 간의 관계
* **원리:** 발화자의 동료들이 타겟(Object)에 대해 이미 가지고 있는 태도가 현재의 발언과 공명(Resonance)할 때, 사회적 파장 점수()를 증폭시킨다. 이는 **"조직적 공세"를 감지하여 네트워크상에서 더 굵은 엣지로 시각화**하기 위함이다.

## 4. 실험 및 검증 (Implementation & Validation)

### 4.1. 고난이도 문장 추출 성능

LLM(GPT-4/HyperCLOVA X)을 활용한 In-context Learning은 한국어 특유의 모호성 처리에 탁월한 성능을 보였다.

* **사례 1 (주어 생략):** *"대통령실을 향해 쓴소리를 쏟아냈다."* → 문맥 추론을 통해 발화자(Subject)를 이전 문단에서 복원 성공.
* **사례 2 (반어법):** *"'기가 막힌 논리'라며 꼬집었다."* → 긍정 단어('기가 막힌')를 부정적 비꼬기(Sarcasm)로 정확히 분류.

### 4.2. DCP 알고리즘 시뮬레이션 결과

자체 개발한 파이썬 시뮬레이터(NetworkX 기반)를 통해 알고리즘의 유효성을 검증하였다.

* **시나리오:** 대변인 B가 야당 대표 C를 비판함 (텍스트 자체 강도: 0.6).
* **알고리즘 분석:** TuringDB 조회 결과, B의 상관인 **당대표 A**가 이미 C를 강하게 혐오(0.9)하고 있음이 확인됨.
* **결과:** 동조 효과(Resonance)가 발생하여 **최종 파장 점수가 0.69로 보정(상승)**됨.
* **해석:** 이는 해당 발언이 단순한 개인의 의견이 아니라, 진영 논리에 기반한 조직적 공세임을 수치적으로 입증한 것이다.

## 부록 (Appendix): DCP 알고리즘 시뮬레이션 코드

```python
import networkx as nx

class PoliticalNetworkSimulator:
    def __init__(self):
        self.graph = nx.DiGraph() # Mocking TuringDB environment
        
    def add_historical_record(self, subject, target, sentiment, weight):
        """과거 관계 데이터 적재"""
        self.graph.add_edge(subject, target, sentiment=sentiment, weight=weight)
        
    def get_allies(self, subject):
        """우호적 관계(Ally) 탐색"""
        allies = []
        if self.graph.has_node(subject):
            for neighbor in self.graph.successors(subject):
                if self.graph.get_edge_data(subject, neighbor)['sentiment'] == 'Positive':
                    allies.append(neighbor)
        return allies

    def dcp_algorithm(self, subject, target, current_sentiment, base_intensity, alpha=0.3):
        """
        [Dynamic Contextual Propagation Algorithm]
        주변 동료들의 태도를 반영하여 현재 발언의 사회적 파장 점수를 보정함.
        """
        allies = self.get_allies(subject)
        resonance_score = 0
        
        for ally in allies:
            if self.graph.has_edge(ally, target):
                history = self.graph.get_edge_data(ally, target)
                # 동료와 나의 태도가 일치하면 공명(Resonance) 발생
                if history['sentiment'] == current_sentiment:
                    resonance_score += history['weight'] 
        
        # 최종 점수 계산: (1-a)*본인점수 + a*공명점수
        final_score = (1 - alpha) * base_intensity + (alpha * resonance_score)
        return min(final_score, 1.0)

```
